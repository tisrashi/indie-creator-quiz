# 独立游戏制作人 · 全能知识挑战

[在线作答](https://tisrashi.github.io/indie-creator-quiz/)

40 道题、100 分，覆盖玩法与关卡、程序与技术、美术与动画、声音与体验、数值与推理和独游杂学。

- 28 道单选、8 道多选、4 道计算选择题，包含 3 道看图题。
- 交卷立即显示总分、各领域得分及错漏题数。
- 答案与解析在交卷后按需展开。
- 自动保存当前浏览器作答，支持暂停计时、重新作答和 JSON / Markdown 导出。

下载 index.html 后，也可以在浏览器中离线打开作答。

网站由 GitHub Pages 发布；更新 main 分支根目录的 index.html 后即可更新网站。
